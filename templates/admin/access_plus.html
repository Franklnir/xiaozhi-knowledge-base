Kebijakan Akses Plus & Auto-Connect:
  • User baru secara default bebas (Akses Penuh) sampai Anda membatasinya secara spesifik di bawah.
  • Jika Slot 2 & 3 dibatasi, token TIDAK dihapus melainkan dinonaktifkan. Saat Anda mengaktifkannya kembali, koneksi bridge XiaoZhi akan otomatis terhubung kembali (auto-connect) tanpa user perlu memasukkan token ulang.
  • Jika kuota playlist dibatasi (misal maks 15 lagu), lagu di atas batas kuota dinonaktifkan (bukan dihapus). Ketika user meminta memutar lagu nonaktif lewat perintah suara, XiaoZhi akan merespon: "Lagu ini telah dinonaktifkan oleh admin. Silakan buka paket langganan Akses Plus."
