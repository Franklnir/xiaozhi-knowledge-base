Firmware Full Factory Merged 0x0 (Khusus ID: esp32s3_cam):
Dirancang untuk board ESP32-S3 baru yang masih kosong. File ini mencakup Bootloader chip, Partition Table, OTA data, Aplikasi AI Voice Assistant, serta seluruh font & aset suara.

Langkah-Langkah Flashing:

  1. Gunakan laptop/PC dengan browser Google Chrome atau Microsoft Edge.
  2. Sambungkan board ESP32-S3 ke komputer dengan kabel data USB.
  3. Klik tombol 🔌 Pilih & Hubungkan Port COM, lalu tentukan port serial ESP32 Anda.
  4. Di Langkah 2, pilih tab 🎯 Preset Firmware lalu klik ⚡ Muat Preset Ini ke Flasher.
  5. Offset otomatis diset ke 0x0 dan baudrate default 460,800 bps.
  6. Klik tombol hijau ⚡ Mulai Flash ke ESP32 dan tunggu progress bar hingga 100%.
🔧 Jika Port Gagal Terhubung / Timeout:

Board perlu dimasukkan ke mode Bootloader:
1. Tahan tombol BOOT (GPIO 0).
2. Tekan tombol RST / EN 1 kali lalu lepas.
3. Lepas tombol BOOT.
4. Klik tombol Pilih & Hubungkan Port COM kembali.

📶 Konfigurasi Wi-Fi Awal Setelah Flashing:

Setelah chip restart, sambungkan perangkat Anda ke hotspot Wi-Fi Xiaozhi-XXXX. Buka browser ke 192.168.4.1 untuk menyambungkan asisten suara ke Wi-Fi rumah/kantor Anda dan memilih tipe layar Anda di portal Wi-Fi.

🔒 Khusus ID: esp32s3_cam: Skema dataset pin di atas telah diprogram secara native di firmware untuk kompatibilitas optimal hardware ESP32-S3 N16R8 CAM. Pengguna dapat berganti jenis layar kapan saja melalui portal Wi-Fi 192.168.4.1 setelah flashing.
