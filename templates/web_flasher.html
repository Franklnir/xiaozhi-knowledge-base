💡 Tips & Bantuan Flashing:
  • Untuk Board Baru Kosong: Gunakan Preset Resmi Full Factory (~9.65 MB) dan alamat offset 0x0.
  • Gunakan browser Chromium modern (Google Chrome, Microsoft Edge, Opera, atau Brave).
  • Pastikan kabel USB adalah kabel data (bukan sekadar kabel charging saja).
  • Jika koneksi timeout atau port tidak merespons: tahan tombol BOOT (GPIO 0), tekan tombol RST / EN 1 kali, lalu lepas tombol BOOT sebelum mengklik Hubungkan.

📖 Panduan Flashing Firmware Xiaozhi (ESP32-S3)

Karakteristik Firmware Full Factory:
File ini dirancang khusus untuk board baru yang masih kosong dari pabrik. Pembeli tidak perlu mem-flash bootloader atau partisi terpisah, karena 1 file ini sudah mencakup seluruh sistem lengkap di alamat 0x0.

Langkah-Langkah Flashing:

  1. Gunakan laptop/PC dengan browser Google Chrome atau Microsoft Edge.
  2. Sambungkan kabel data USB ESP32-S3 ke komputer.
  3. Klik tombol 🔌 Pilih & Hubungkan Port COM, lalu pilih port perangkat Anda (misal: USB Serial JTAG atau CH343).
  4. Klik ⚡ Muat Preset Ini (atau upload file firmware jika Anda memiliki file lokal).
  5. Pastikan Offset adalah 0x0 (sistem otomatis mengunci offset ke 0x0 saat preset dimuat).
  6. Baudrate direkomendasikan 460,800 bps.
  7. Klik tombol hijau ⚡ Mulai Flash ke ESP32 dan tunggu progress bar hingga 100%.
🔧 Jika Port COM Tidak Terdeteksi / Gagal Connect:

Board ESP32-S3 mungkin perlu dimasukkan ke mode Bootloader manual:
1. Tahan tombol BOOT (GPIO 0).
2. Tekan tombol RST / EN 1 kali lalu lepas.
3. Lepas tombol BOOT.
4. Klik tombol Pilih & Hubungkan Port COM kembali.

📶 Pengaturan Wi-Fi Pertama Kali Setelah Flashing:

Setelah flashing 100% selesai dan chip restart, ESP32 akan memancarkan hotspot Wi-Fi bernama Xiaozhi-XXXX. Sambungkan HP/Laptop Anda ke Wi-Fi tersebut, buka browser ke 192.168.4.1, lalu masukkan nama & password Wi-Fi rumah/kantor Anda.

🔑 Minta Izin Akses Preset Flasher

Preset ESP32-S3 N16R8 / CAM Full Factory adalah firmware komersial. Kirimkan pesan atau nomor pesanan Anda ke Admin untuk verifikasi aktivasi.
