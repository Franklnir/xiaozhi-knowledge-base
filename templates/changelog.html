Buka Web Flasher
Wajib Flash Ulang (.bin) Update Firmware ESP32

Diperlukan jika pembaruan menyentuh kode di dalam chip ESP32 (pipeline audio I2S/Opus, driver layar LCD/OLED, wakeword, perbaikan bug Wi-Fi/memori MCU, atau pinout board).

Cara Update: Colokkan ESP32 via kabel USB → buka Web Flasher → pilih preset & versi terbaru → klik Mulai Flash Firmware.
Otomatis / Cukup Reconnect (Server/MCP) Update Cloud & Tools AI

Untuk pembaruan pada server AI, 66 FastMCP tools, memori percakapan, backend musik YouTube, atau logika kontrol smart home. Semua berjalan di sisi cloud server.

Cara Update: Tidak perlu flash ulang (.bin). Perangkat langsung menikmati update; cukup matikan-nyalakan ulang atau reconnect Wi-Fi/WebSocket jika sesi lama masih tersambung.
