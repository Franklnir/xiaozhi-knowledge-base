🔌 Apa itu MCP?

MCP (Model Context Protocol) adalah protokol yang menghubungkan asisten suara XiaoZhi dengan knowledge base EduSmart. Dengan MCP, XiaoZhi bisa membaca materi, mengontrol smarthome, memutar lagu, dan lainnya.

📋 Langkah-Langkah Setup MCP
1
Buka Website XiaoZhi
Kunjungi https://xiaozhi.me dan login ke akun XiaoZhi kamu.
2
Ambil Token MCP
Di halaman XiaoZhi, cari menu "MCP Endpoint" atau "Koneksi MCP".
Salin URL yang dimulai dengan wss://
Contoh: wss://api.xiaozhi.me/mcp/?token=eyJhbGciOiJFUzI1Ni...
💡 Tips: Pastikan menyalin URL LENGKAP, bukan hanya token-nya saja!
3
Tempel di Dashboard EduSmart
Kembali ke halaman Dashboard EduSmart.
Cari bagian "Koneksi XiaoZhi" di sidebar kanan.
Tempel URL MCP yang sudah disalin, lalu klik "Simpan".
4
Tunggu Koneksi
Setelah menyimpan, sistem akan mencoba menghubungkan ke XiaoZhi.
Tunggu beberapa detik hingga status berubah menjadi "Terhubung".
5
Verifikasi di XiaoZhi
Kembali ke https://xiaozhi.me.
Cek apakah status MCP sudah "Online" atau "Terhubung".
Jika sudah, XiaoZhi sudah bisa membaca data dari EduSmart!
⚠️ Troubleshooting MCP
Jika koneksi gagal:
  • Pastikan URL dimulai dengan wss://
  • Pastikan menyalin URL LENGKAP (bukan hanya token)
  • Coba hapus dan simpan ulang token
  • Periksa koneksi internet
🎵 Setup Putar Lagu YouTube di ESP32

Kamu bisa meminta XiaoZhi memutar lagu dari YouTube. Audio akan diputar melalui speaker ESP32.

📋 Persiapan
1
Pastikan MCP Terhubung
Sebelum bisa memutar lagu, pastikan koneksi MCP sudah Online di Dashboard.
2
Aktifkan Fitur YouTube
Di Dashboard, pastikan toggle "YouTube Music" dalam keadaan aktif (centang hijau).
3
ESP32 Harus Terhubung
Pastikan ESP32/audio player sudah terhubung ke internet dan terdaftar di sistem.
🎤 Cara Memutar Lagu
1
Gunakan Perintah Suara
Katakan ke XiaoZhi:
"Putar lagu [judul lagu]"
"Mainkan musik lofi"
"Cari lagu Bohemian Rhapsody"
2
XiaoZhi Akan Mencari
XiaoZhi akan mencari lagu di YouTube dan menampilkan hasilnya.
3
Audio Diputar di ESP32
Audio akan otomatis diputar melalui speaker ESP32 yang terhubung.
📝 Konfigurasi Firmware ESP32
1
Download Firmware
Download file esp32_youtube_player.ino dari repository.
2
Edit Konfigurasi WiFi
Buka file dan edit bagian WiFi:
const char* ssid = "NAMA_WIFI_KAMU";
const char* password = "PASSWORD_WIFI";
3
Upload ke ESP32
Upload firmware menggunakan Arduino IDE atau PlatformIO.
⚠️ Catatan Penting:
  • ESP32 harus terhubung ke WiFi yang sama dengan server
  • Speaker harus terhubung ke ESP32
  • Pastikan fitur YouTube aktif di Dashboard
🏠 Smart Home Virtual

Smart Home Virtual adalah simulasi kontrol perangkat rumah menggunakan relay virtual. Kamu bisa mengontrol lampu, AC, alarm, dll melalui perintah suara.

📋 Daftar Ruangan
Channel Ruangan Perangkat Contoh Perintah
1 Ruang Tamu Lampu utama "Nyalakan lampu ruang tamu"
2 Dapur Lampu dapur "Matikan lampu dapur"
3 Kamar Mandi Lampu kamar mandi "Nyalakan lampu kamar mandi"
4 Kamar Tidur Utama Lampu kamar utama "Matikan lampu kamar tidur"
5 Teras Lampu teras "Nyalakan lampu teras"
6 Basement Alarm "Nyalakan alarm"
7 Kamar Tidur 2 Lampu kamar kedua "Matikan lampu kamar 2"
8 Ruang AC AC "Nyalakan AC"
🎤 Contoh Perintah Suara
Kontrol satu ruangan:
"Nyalakan lampu ruang tamu"
"Matikan AC"
"Hidupkan alarm"
Kontrol semua perangkat:
"Nyalakan semua lampu"
"Matikan semua perangkat"
Cek status:
"Status smarthome"
"Lampu mana yang menyala?"
❓ Pertanyaan Umum
Q: XiaoZhi tidak bisa membaca materi saya?
A: Pastikan koneksi MCP sudah Online di Dashboard. Jika belum, ulangi langkah setup MCP.
Q: Lagu YouTube tidak bisa diputar?
A: Periksa:
  • Fitur YouTube aktif di Dashboard
  • ESP32 terhubung ke WiFi
  • Speaker terhubung ke ESP32
  • MCP dalam status Online
Q: Smart home tidak merespons?
A: Pastikan:
  • MCP dalam status Online
  • Perintah suara sesuai dengan nama ruangan
  • Gunakan perintah yang jelas seperti "Nyalakan" atau "Matikan"
Q: Berapa banyak materi yang bisa disimpan?
A: Tergantung batas yang ditetapkan admin. Default: 3 materi, maksimal 6000 kata per materi. Hubungi admin jika butuh kapasitas lebih.
Q: Bagaimana cara mengubah tema?
A: Di sidebar bawah, ada dropdown "Tema". Pilih tema yang diinginkan: Neo Brutalism, Dark, atau Original.
Q: Apakah data saya aman?
A: Ya! Semua data dienkripsi menggunakan Fernet encryption. Token MCP disimpan dalam bentuk terenkripsi di database.
🆘 Butuh Bantuan?
Jika mengalami masalah yang tidak tercantum di sini, hubungi admin melalui:
  • Chat langsung di aplikasi
  • Hubungi admin melalui kontak yang tersedia
